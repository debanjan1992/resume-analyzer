# AI Resume Matcher & JD Analyzer

An advanced AI-powered tool designed to bridge the gap between job seekers and recruiters by analyzing the compatibility between resumes and job descriptions (JD). This project leverages state-of-the-art matching techniques to provide actionable insights for Applicant Tracking System (ATS) optimization.

## Features

- **Automated Resume Parsing**: Extracts structured data from PDF and DOCX formats, including contact information, skills, experience, and education.
- **JD Requirement Extraction**: Identifies key requirements, mandatory skills, and preferred qualifications from complex job descriptions.
- **Similarity Analysis**: Uses sophisticated scoring algorithms to evaluate the alignment between the resume and the job description.
- **Keyword Gap Analysis**: Highlights specific industry terms and technical skills missing from the resume that are critical for the role.
- **Real-time Scoring**: Provides an instant compatibility score to help candidates prioritize which roles to apply for.

## Comparison Parameters

When a resume is compared against a Job Description, the system generates the following parameters:

1.  **Overall Match Score**: A percentage representing the total alignment between the candidate's profile and the job requirements.
2.  **Missing Keywords**: A list of high-priority skills or tools mentioned in the JD that were not detected in the resume.
3.  **Skill Match**: A detailed breakdown of technical and soft skills found in both the resume and the JD.
4.  **Experience Alignment**: An evaluation of how the candidate's professional history matches the seniority and domain requirements of the role.
5.  **Education Match**: A check for required degrees, certifications, or specific academic backgrounds.
